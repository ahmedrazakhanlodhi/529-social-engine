# How to use the Content Hub

## 1. Start on Home
Look for three things: what is scheduled this week, what still needs review, and any repetition warnings. The recommended next action points to one useful item to work on.

## 2. Build the week in Plan
The planner proposes Monday / Wednesday / Friday content using only approved items. Read the reason under each recommendation. Replace a recommendation when there is a timely reason to do so, select channels, assign an owner, and add the week to the calendar.

## 3. Maintain the Content Library
Use the bundled Compendium facts as controlled copy. Add FAQs, member stories, events, employer material, and other sources through **Add a new content item**. New material begins as Draft.

## 4. Review and approve
Open **Approvals**. Move content through Fact checked and Communications review before Approved. Enter reviewer initials/name when recording a fact check or approval.

## 5. Create the publication package
Open **Create**, select approved content, edit the creative wrapper, keep the controlled factual core unchanged, review creative warnings, preview the graphic, and download the ZIP package.

## 6. Amplify through members
Open **Member Toolkits** and generate the member package. Only replace bracketed state placeholders with verified information.

## 7. Mark content Published and record results
Update the Calendar status. Then open **Performance** and add published executions to the tracker. Enter platform results as they become available.

## 8. Review signals, not just follower count
The Performance page emphasizes engagement, clicks, shares/saves, website sessions, and member reposts. Treat small samples as directional only.
