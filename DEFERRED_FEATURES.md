# Intentionally deferred

The following were deliberately not added in this build because they would add complexity before solving the core communications workflow:

- Direct publishing to LinkedIn, Instagram, or Facebook
- OAuth/social-platform account management
- Autonomous AI campaign generation
- Enterprise SSO / role-based access control
- Paid cloud database dependency
- Full digital-asset-management system
- Automatic social-platform analytics APIs
- Drag-and-drop calendar dependency

The architecture leaves room to add these later if team use demonstrates a real need.
